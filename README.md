# SmartLock Mobile

App Android para controlar una cerradura inteligente por Bluetooth.
Hecha con Kotlin y Jetpack Compose.

## Qué hace
- Login y registro de usuarios (el primero queda como administrador)
- Control de la cerradura por Bluetooth
- Historial de eventos guardado en SQLite

## Cómo correrla
1. Abrir la carpeta en Android Studio
2. Esperar el sync de Gradle
3. Ejecutar en un emulador o celular
